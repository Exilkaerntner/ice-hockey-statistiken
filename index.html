Wie passt das zusammen?

Das hier ist ein reines Hobby-Projekt – entstanden aus zwei Leidenschaften: Eishockey und künstliche Intelligenz. Kann man mit sorgfältigem Prompt Engineering eine vollständige, funktionale Statistikseite erstellen, ohne eine einzige Zeile Code selbst zu schreiben?

Die Antwort sehen Sie hier. Alles – jede Tabelle, jede Berechnung, jede Zeile HTML, CSS und JavaScript – wurde von claude.ai generiert. Ich schreibe den Code nicht, ich formuliere die Anforderungen.

Ich möchte damit nicht in Konkurrenz zur offiziellen ice.hockey Homepage treten. Dazu fehlt noch einiges an Wissen – und die Profis dort machen einen hervorragenden Job.
„Wer heute im Finanz- und Sportdatenbereich KI ignoriert, verhält sich wie jemand, der 1995 das Internet als Spielerei abgetan hat."
Da ich ein Eishockey-Enthusiast bin, war die heimische Liga ein logisches Projekt. Die Daten reichen zurück bis 1950 – mit dem Kärntner Derby als Herzstück der Frühzeit.
